# 科技视频 Skill V3：升级与验证说明

已根据本次逐项确认完成 V3 安装包与可运行工程。默认服务对科技、AI 感兴趣的普通用户，覆盖科技资讯、最佳实践、案例合集和自制工具／产品分享。

主画幅为 **3:4（1080×1440）**，同时交付 **9:16（1080×1920）** 与 **16:9（1920×1080）**。三版使用同一套已确认文案和事件时间轴，逐镜分别构图。视频长度由内容价值与观看节奏决定。

## 创作方向

运动品质以苹果 motion 的优雅、精确、连续与巧思为参考，同时采用更紧凑的信息推进。每条内容可以探索自己的色彩、材质、主体、空间关系与视觉隐喻。

脚本围绕观众的具体疑问、好奇心和使用场景展开，讲清关键原因、条件和取舍。首句、首镜和声音共同建立观看期待，中段持续交付发现、证据、解释和观点。四类内容有各自可探索的叙事力量，具体结构由当前材料决定。

沿用 Seed-TTS 2.0 清爽男大声线，表达阳光、青春、有活力、有亲和力。制作以效果为先，优先利用已有 Grok 订阅进行所需的图像与视频生成。

## 这次真正改了什么

| 部分 | V3 的实现 |
|---|---|
| 创作权限 | 开放 `src/shots/` 专属 React／Remotion 镜头；可以扩展构图、主体、连续动作和转场。JSON 组织内容与时间，代码实现具体表现。 |
| 内容组织 | 支持多链接、文档、图片、视频和作者资料，分别保存来源；观点与事实引用保持归属。 |
| 节奏与长度 | 以内容和观看体验决定长度；段落与镜头可以多对多对应，三种画幅与“长短版本”分开处理。 |
| 音画时间轴 | 实际音频时间戳、语义事件、字幕、镜头、音乐与转场共同编译到整数帧；原有字幕时码保留。 |
| 配音迭代 | 按段合成和缓存；文案／音频指纹变化后重新对齐。干运行只打印计划，不生成伪装成真实配音的静音文件。 |
| 用户确认 | 完整文案、实际前十秒动态样片两个确认点；中后段独立修改继续自主完成。 |
| 确认延续 | 开头源文件变化时可重新渲染，对比新旧样片的解码画面和音频；完全相同才继承原确认，保留原回复与样片。 |
| Grok 素材 | 统一调用接口、视觉方向提示、参考图、生成记录、原件保留和素材登记；视频规范化为单一主视频流。 |
| 多 Agent | 同一创作核心与脚本，分别提供 Grok CLI、Cursor、Claude Code 的安装入口和宿主操作说明；同时保留 Codex 入口。 |

新的主说明为 89 行，详细机制按需放在参考文件中。默认创作说明以目标、判断依据和启发示例为主。旧版固定模板的校验要求未进入 V3 默认创作流程。

## 实际完成的验证

- **18 项自动化测试通过**：9 项时间轴测试、9 项工作流测试，覆盖转场时序、旁白连续、实际时码保留、循环事件、文案顺序、音频变更、来源引用以及确认记录的有效性。
- **三画幅目标尺寸渲染成功**：1080×1440、1080×1920、1920×1080，均有音轨。工程测试片各为 360 帧／30 fps，即视频画面 12 秒；容器含 AAC 尾部时长约 12.053 秒。这是测试夹具长度，不是正式视频预设。
- **音频时间验证通过**：上一镜在 2.0 秒结束，旁白轨在 2.1 秒仍正确播放；2.5 秒的间隔与 3.1 秒的下一段音轨正确出现。三版观测一致。
- **可复现的渲染测试已运行**：附 `tests/render_smoke.py`，会生成隔离的合成音调夹具、三画幅文件和结果 JSON，并验证开头画面／音频一致时的确认延续。
- **Grok 真实接口测试成功**：通过本机 Grok 1.0.21 生成图片，再以该图生成约 6 秒视频，并检查抽帧。生成视频实际尺寸为 816×1104；原文件附带封面视频流，规范化后保留一个主视频流和音频，原件另外保存。
- **技能被发现**：Grok 在独立测试项目中正确发现 V3。Cursor 3.19.10、Claude Code 2.1.259 的本机可执行入口已核对；安装路径参考当前官方文档。
- **包检查通过**：技能主文件校验、TypeScript 检查、Python 命令帮助、Bash 语法和本地引用链接检查均通过。ZIP 共 59 个文件，排除了依赖目录、缓存、渲染产物和凭据文件；初始确认记录为空。

机器可读结果：verification/results.json（历史附件未随本版分发；当前结果见 [VERIFICATION](../VERIFICATION.md)）。音轨观测：verification/audio-verification.json（历史附件未随本版分发；当前结果见 [VERIFICATION](../VERIFICATION.md)）。可复现渲染记录：verification/render-smoke.json（历史附件未随本版分发；当前结果见 [VERIFICATION](../VERIFICATION.md)）。

## 验证范围

本轮音轨渲染使用明确标记的合成音调测试夹具，证明调度和输出行为；它不代表青春男声的试听质量。当前执行环境没有读取到 `SEED_AUDIO_KEY`，因此未调用真实 Seed 配音，也未完成真实人声的 Whisper 转写与听音校订。

Grok 的技能发现和媒体生成已实测；三个 Agent 各自从真实选题出发、经过用户两个确认点、完成整条作品的行为评测尚未执行。包内的 5 个评测请求是后续可执行的用例，不被计作已通过的创作评测。

技术示例与生成素材用于检查接口，不作为苹果级审美、真实观众留存或平台传播效果的通过证据。第一条真实选题仍按“全文确认 → 前十秒确认 → 全片与三画幅复看”的流程验收。
