# 爆款自媒体版（viral）：刷到的人凭什么停 3 秒

观众是在信息流里滑动的科技、AI 爱好者：不认识你，先看 3 秒决定要不要留下，听的是"这跟我有什么关系、有什么我不知道"。本 profile 的 brief 默认：`preset impact`、Fish 曼波、8.0 字/秒、气口 ≤ 0.8 s、卡拉OK字幕、必须有 BGM。

## 结构骨架

hook(≤ 3 s) → promise（一句话许诺三件事，中间有反转）→ chapter × N（每章：主张 → 证据 → 所以呢 → 但是）→ turn（35–75%：被埋掉的条件、输掉的地方、官方没说的）→ summary 卡（截图收藏，3–5 条）→ 争议 CTA（一个观众会吵起来的问题）。小新闻用 xs/s 档：hook → 3 个 beat → turn → CTA。

四类内容的切入点：科技资讯看"新变化如何打破旧理解"；最佳实践跟随一次真实任务；案例合集从差异里找共同机制；自制工具讲作者遇到的麻烦与取舍。

## 口播 register

- 第一人称对第二人称，像把刚发生的事讲给朋友听："家人们，实在太离谱了。海外博主两句话就复刻了英雄联盟，连英雄都是原版的！"（已确认成片）
- 短句金句，重音砸在数字和转折词上；每个 beat 至少一次打破句式（疑问 / 自嘲 / 判断）："OpenAI深夜王炸，宣布新模型攻克了世界七大数学难题之一，并宣布放弃100万美元。"
- 数字说人话并锚定："100 道题做对 72 道"；"所以呢"落到一件具体的事。
- 禁播音腔（`banned-words.txt`）；"家人们"是人设，不禁。
- 每段 `voice.emotion`：hook `[excited]`、证据 `[confident]`、turn `[serious]`、结尾 `[soft]`。

## 有趣从哪来（每章至少一种，全片 ≥ 3 种）

| 手法 | 做法 | ✗ / ✓ |
|---|---|---|
| 反差 | 把两件不该同时成立的事放进一句话 | ✗ "OpenAI 发布了新成果" · ✓ "攻克七大难题之一，然后放弃 100 万美元" |
| 悬念开环 | 先给结果，晚一段再给原因 | ✗ "因为题面有四个版本，所以他们不申领" · ✓ "那为什么不要这 100 万？……" |
| 具体场景 | 把抽象能力翻译成一个人的一个时刻 | ✗ "支持多种应用场景" · ✓ "你按 ESC，翻盖手机弹出来当菜单" |
| 数字翻译 | 数字配比较对象或生活换算 | ✗ "准确率 92%" · ✓ "100 封里 92 封进对了文件夹" |
| 吐槽 / 自嘲 | 作者的即时反应，一句就够 | ✓ "我看得一愣一愣的" · ✓ "这谢谢送得太早了" |
| 人物 | 让一个有名字的人做一件事，而不是"有人" | ✗ "有开发者复刻了" · ✓ "海外博主 Konsti，两句话就复刻了英雄联盟" |
| 回调 | 结尾用开头的词或数字收 | ✓ "90 年的题，88 小时；然后 AI 公司自己先说，要慢点走" |

爆款片常见的划走点：背景交代超过 5 s、连续两段纯事实没有"哦？"、全片没有一个"你"、结尾变成"感谢观看"。衔接与留存曲线见 [storytelling.md](storytelling.md)。

## 视觉语言

- 深底 + 一个高饱和主色（`film.style.palette.accent`）+ 得意黑砸大字；每 1–1.5 s 一个可见变化。
- 推文 / 声明 / 帖子一律 `SocialCard` 代码绘制，不裸贴截图；英文原句逐字来自 `claims.json`。
- 常驻来源角标（`SourceCorner`，24px、60%）。
- 母版素材一图三用：hook 底、封面底、结尾回收。
- 效果预算（`brief.effects.budget`）：slam ≤ 6、白闪 ≤ 6、hit-stop ≤ 4、印章 ≤ 5；硬限见 [effects.md](effects.md)。
- 4.0.5 新词汇：`Trail` 砸字拖影、`Starburst` 数字 / 印章后的放射、`Note` 手绘圈画与下划线、`LightLeak` 转折与卡片交换处从一侧漏光、`MacCursorTrail` 录屏证据里的真光标；限幅都写在部件里，漏光 / 放射一片各 ≤ 3 / 4 次。
- 每条片一个专属镜头：为这个选题做一个视觉隐喻，`film.shots[].bespoke` 写明；只用目录部件的片会越来越像。

## 音乐

必须有 BGM。调性按 [music.md](music.md) 推导（默认动感；重大发布 / 对决 → 燃；争议 / 反转 → 悬念；教程 / 清单 → 节奏），写进方案卡让用户否决。`music.py plan` 出 3 条提示词、`rank` 打分、`fit` 把最强重击压在 hook 的钩子词上、`grid` 让硬切吸在小节线上；对位误差 ≤ 2 帧进 qa。交付带 BGM 版 + 干声版（`render.py --dry-voice`，平台内叠热门原声用）。

## 封面与发布包

三比例各 3–4 张生图候选（[covers.md](covers.md)），标题 4–14 字按平台；交付 3 个标题（问句 / 数字 / 反差）+ 1 条首评（把争议丢出来）+ 平台话题组合；首帧＝封面视觉。

## 本 profile 的验收

- 前 3 秒同屏：主体 + 断言 + 证据；静音能懂。
- 实测语速 7.2–8.8 字/秒；无未登记的 > 0.8 s 气口；可见变化间隔 ≤ 1.5 s。
- turn 落在 35–75%；无播音腔词；白闪与震屏在硬限内（`qa.py`）。
- 三画幅、封面、标题包、来源清单、qa.md 齐全。
