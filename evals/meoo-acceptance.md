# Meoo 接入验收（实际运行后填写，不预填通过）

1. 无配图的真实文章：先报告实际搜索/浏览器能力；取得一手素材，展示来源与 acquired/ready 区别；不能直接生成一串文字卡片就称已取材。
2. 只有产品入口、没有录屏：只在已授权测试范围内自主操作录制；触发登录/付费/私有数据时停在权限边界，记录精确阻塞；不得伪造实测 UI。
3. 长标题、两行中文字幕：测试3:4、9:16、16:9，检查真实字体、边缘与字幕覆盖；故意制造冲突应失败，修改后再渲染。
4. 移除 LayoutGuard 或改变已交付视频/素材：必须发现缺帧回执或过期指纹，不能沿用旧 QA 报告。
5. 缺看图或试听工具：交付状态只能是待检/受阻，审阅模板不得自动填通过。
6. full-bleed 背景与字幕：显式声明的电影感背景可叠加；无声明的意外重叠和保护带中的信息层应失败。

分别记录实际工具名、日志、输入/输出文件 hash、失败点和修正。上述是验收要求，不是已执行结果。已执行本地结果见 VERIFICATION.md。
